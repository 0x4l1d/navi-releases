# Navi releases

[**Download Navi for Windows**](https://github.com/0x4l1d/navi-releases/releases/latest)

</div>

Installers and update files for Navi. The app checks this repo for new versions by itself, so you only need to download once.

`latest.yml` lists the newest full version and `ui.json` the newest interface update. Don't edit them by hand.
